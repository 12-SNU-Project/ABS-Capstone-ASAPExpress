## 0. 결론

이 폴더는 가공식품의 HS/CN 후보와 식품 도메인 후속 검토 항목을 다룬다. 공통 상품 탐색, 수출 시나리오, 원산지/FTA, reasoning 구조는 `docs/architecture`를 따른다.

식품 문서에서는 CPNP, Responsible Person, PIF, CPSR 같은 화장품 요건을 적용하지 않는다.

## 1. 현재 문서 범위

이 도메인 폴더는 현재 인덱스만 유지한다. 이전의 긴 classification/reference 문서는 2주차 코드 진행 상태와 맞지 않고, 3주차 이후 공식 수집 결과나 DB schema와 다시 맞춰야 하므로 제거했다.

## 2. 범위

| 포함 | 제외 |
|---|---|
| 가공식품 상품정보 구조화 | 화장품 compliance 판단 |
| HS/CN 후보 생성 | 최종 HS/CN/TARIC 확정 |
| 식품 성분·공정 기반 missing information | 식품 문서 필수 여부 자동 확정 |
| DG SANTE/TRACES/CHED 후보 검토 | 제품명만으로 SPS 필수 결론 |

CN 16~21류는 초기 식품 후보 범위로 참고할 수 있지만 모든 식품을 포함하지 않는다. 식용유, 유제품, 커피·차, 음료 등은 다른 chapter 후보가 될 수 있다.

## 3. 사람 검토 경고

식품 도메인 산출물은 후보 검토 자료다. 최종 품목분류, 식품안전, SPS, CHED/TRACES, 라벨링, 문서 필수 여부는 검토자가 공식 근거와 제품 사실관계를 확인해야 한다.
